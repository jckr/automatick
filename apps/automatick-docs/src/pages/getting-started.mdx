# Getting started

## Installation

Install `automatick` with whichever package manager your project uses:

```bash
npm install automatick
```

```bash
pnpm add automatick
```

```bash
yarn add automatick
```

```bash
bun add automatick
```

React and React DOM are optional peer dependencies. If you plan to use the React adapter (the `<Simulation>` component, `useSimulation`, the canvas hook, the built-in controls), install them too:

```bash
npm install react react-dom
```

automatick targets React 18 and newer, and requires Node 22.12 or newer for local development.

## Where things live

The package ships the simulation engine and the React adapter side by side, exposed as subpath exports:

- `automatick` and `automatick/sim` — the engine and `defineSim`, no React dependency.
- `automatick/react/simulation`, `automatick/react/hooks`, `automatick/react/controls`, `automatick/react/canvas`, `automatick/react/performance` — the React adapter.
- `automatick/worker/runner`, `automatick/worker/create`, `automatick/worker/protocol` — helpers for running a sim in a Web Worker.

You only import the subpaths you actually use, so a non-React project never pulls React into its bundle.

Once installed, head to the [tutorial](/guide/tutorial) to build your first simulation.
